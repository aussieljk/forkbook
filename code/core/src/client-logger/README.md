# Forkbook Logger

Any client-side logging that is done through storybook should be done through this package.

Examples:

```js
import { logger } from '@aussieljk/forkbook/internal/client-logger';

logger.info('Info message');
logger.warn('Warning message');
logger.error('Error message');
```

For more information visit: [forkbook.ljk.dev](https://forkbook.ljk.dev)
