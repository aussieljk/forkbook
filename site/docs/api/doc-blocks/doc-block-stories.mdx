# Stories block

`Stories` shows all stories of the stories file, each in a canvas. Autodocs uses it.

```mdx
<Stories title="Examples" includePrimary={false} />
```

| Prop | What it does |
| --- | --- |
| `title` | The heading. The default is `'Stories'`. |
| `includePrimary` | Shows the first story too. The default is `true`. |
