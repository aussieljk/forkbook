# Design integrations

## Embed Storybook in Figma with the plugin

The Storybook plugin for Figma needs Chromatic. Forkbook does not support it.

## Embed a story

To show a story in another page, use the story URL in an `iframe`:

```html
<iframe src="https://ui.example.dev/iframe.html?id=forms-button--primary&viewMode=story" width="400" height="200"></iframe>
```

To link to a design from a story, add a link in the description or in a docs page.
