# Names and hierarchy

The sidebar groups stories by their title.

## Structure and hierarchy

The `title` of the meta sets the place in the sidebar. Use `/` to make groups:

```tsx
const meta = {
  title: 'Forms/Inputs/Text field',
  component: TextField,
} satisfies Meta<typeof TextField>;
```

Without a `title`, Forkbook makes the title from the file path. For example, `src/forms/text-field.stories.tsx` gets the title `Forms/Text Field`.

### How the indexer reads the title

Forkbook reads `title` and `tags` from the source code. It does not run the file. It can read a literal value, and a spread of a local object:

```tsx
const base = { title: 'Forms/Text field', tags: ['autodocs'] };

const meta = { ...base, component: TextField } satisfies Meta<typeof TextField>;
```

It cannot read a value from a function call or from an import. Then it shows a warning with the file and the field (`title` or `tags`). Write a literal value to fix it.

## Sort the stories

Set `parameters.options.storySort` in `.forkbook/preview.ts`:

```ts
const preview: Preview = {
  parameters: {
    options: {
      storySort: { order: ['Introduction', 'Forms', ['Inputs', 'Buttons'], '*'] },
    },
  },
};
```

`*` is for all other titles.

## Story IDs

The ID of a story comes from its title and its export name: `forms-inputs-text-field--primary`. The URL uses the ID. See [Permalink to stories](/docs/configure/sidebar-and-urls#permalink-to-stories).
