# Parameters

Parameters are static data about a story. Addons read them. For example, `layout` sets the layout of the canvas, and `backgrounds` sets the background options.

```tsx
export const Wide: Story = {
  parameters: { layout: 'fullscreen' },
};
```

## Levels

You can set parameters in `.forkbook/preview.ts`, in the meta and in a story. Forkbook merges objects. A lower level replaces the same key of a higher level.
