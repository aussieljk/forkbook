# Forkbook

Forkbook is a small, fast fork of Storybook. Use it to build, test and document UI components one at a time.

Forkbook is one npm package: `@aussieljk/forkbook`. Each part of Storybook is a subpath of that package, for example `@aussieljk/forkbook/test` or `@aussieljk/forkbook/react-vite`.

## What Forkbook supports

- React with Vite (`@aussieljk/forkbook/react-vite`).
- Next.js with Vite (`@aussieljk/forkbook/nextjs-vite`).
- React Native on iOS, in Expo apps (`@aussieljk/forkbook/react-native`).

Forkbook uses Vite 8 only. It does not support webpack or other renderers.
