# Environment variables

## In the preview

Variables that start with `FORKBOOK_` or `VITE_` are available in the preview as `import.meta.env.FORKBOOK_X`. Forkbook reads `.env` files as Vite does.

```sh
FORKBOOK_API_URL=https://api.example.dev bun run forkbook
```

```ts
const url = import.meta.env.FORKBOOK_API_URL;
```

Other variables are not in the browser. This keeps secrets out of the build.

## Variables that Forkbook reads

| Variable | What it does |
| --- | --- |
| `FORKBOOK_DISABLE_TELEMETRY` | Sends no telemetry: no error reports and no OpenTelemetry data. |
| `FORKBOOK_SENTRY_DSN` | Sends error reports to this Sentry DSN. An empty string stops error reports. See [Telemetry](/docs/configure/telemetry). |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | Sends telemetry with OpenTelemetry to this address. Without it, Forkbook sends no OpenTelemetry data. See [Telemetry](/docs/configure/telemetry). |
| `FORKBOOK_PORT`, `FORKBOOK_HOSTNAME`, `FORKBOOK_CONFIG_DIR`, `FORKBOOK_STATIC_DIR`, `FORKBOOK_OUTPUT_DIR`, `FORKBOOK_OUTPUT_FILE` | The same as the CLI options. A CLI option wins over its variable. See [CLI options](/docs/api/cli-options). |
| `FORKBOOK` | Forkbook sets it to `true` while it runs. It also sets `STORYBOOK` to `true` for third-party packages. |
| `FORKBOOK_ENABLED` | (React Native) Shows Forkbook in the app. See [React Native](/docs/get-started/frameworks/react-native). |

In Storybook these names started with `STORYBOOK_` or `SBCONFIG_`. Forkbook does not read the old names.
