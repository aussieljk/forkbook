# MDX

An MDX file is markdown with JSX. Use it for pages that you write yourself.

```mdx
import { Meta, Canvas, Controls } from '@aussieljk/forkbook/addon-docs/blocks';

import * as ButtonStories from './button.stories';

<Meta of={ButtonStories} />

# Button

Use a button for the main action of a page.

<Canvas of={ButtonStories.Primary} />

<Controls />
```

- `<Meta of={...} />` attaches the page to a stories file.
- `<Meta title="Guides/Colours" />` makes a page that is not attached.

Add MDX files to `stories` in `.forkbook/main.ts`, for example `'../src/**/*.mdx'`.

Each page of this site is an MDX file.

## Tables and other GitHub markdown

GitHub-flavoured markdown is on by default: tables, task lists, strikethrough and links from plain URLs. To turn it off, set `gfm: false` in the options of the docs addon:

```ts
addons: [{ name: '@aussieljk/forkbook/addon-docs', options: { mdxPluginOptions: { gfm: false } } }],
```

## Infinite scroll

When you scroll to the end of a docs page, the next docs page (in sidebar order) shows below it. The sidebar and the URL follow the page that you read. Story pages do not change.

To turn it off, set the `docs.infiniteScroll` parameter to `false` in `.forkbook/preview.ts`:

```ts
parameters: { docs: { infiniteScroll: false } }
```
