# ESLint plugin

Forkbook does not have an ESLint plugin. The Storybook ESLint plugin (`eslint-plugin-storybook`) checks `@storybook/*` imports, so it does not fit Forkbook.

Use your normal linter (for example oxlint) on stories files.
