# Forkbook: set up stories for the real components

Run this command and follow its output. It gives the setup steps for the framework of this project (React with Vite, Next.js with Vite, or React Native):

```sh
npx forkbook skills setup
```

If the project does not have Forkbook yet, run `npx @aussieljk/forkbook init` first.
