## Serving static files via the Forkbook configuration

`staticDirs` in `.forkbook/main.ts` serves folders at the root of Forkbook:

```ts
staticDirs: ['../public', { from: '../assets/fonts', to: '/fonts' }],
```

A file `public/logo.png` is then at `/logo.png`. `forkbook build` copies the folders into the output.
