# Forkbook Accessibility Addon

The @aussieljk/forkbook/addon-a11y package provides accessibility testing for Forkbook stories. It uses axe-core to run the tests.

## Getting Started

### Add the addon to an existing Forkbook

```bash
npx forkbook add @aussieljk/forkbook/addon-a11y
```

[More on getting started with the accessibility addon](https://storybook.js.org/docs/writing-tests/accessibility-testing#accessibility-checks-with-a11y-addon?ref=readme)

Learn more about Forkbook at [storybook.js.org](https://storybook.js.org/?ref=readme).
