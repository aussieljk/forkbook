# Forkbook: write a story

The imports and the story format depend on the project. For example, a preview file that uses `definePreview` needs CSF Factories. Run this command to get the rules for this project, and follow them:

```sh
npx forkbook skills write-story
```

If the Forkbook MCP server is connected, its story instructions tool gives the same rules.
