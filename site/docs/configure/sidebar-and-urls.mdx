# Sidebar and URLs

## Permalink to stories

Each story has a URL: `/?path=/story/<story id>`. A docs page has `/?path=/docs/<page id>`. The story ID comes from the title and the export name, for example `forms-text-field--primary`.

To open only the story, with no Forkbook UI, use `/iframe.html?id=<story id>&viewMode=story`.

## The sidebar

- The title of each meta sets the groups. See [Names and hierarchy](/docs/writing-stories/naming-components-and-hierarchy).
- `parameters.options.storySort` sets the order.
- The tag filter shows or hides stories by tag.

## Options of the sidebar

Set them in `.forkbook/manager.ts`:

```ts
import { addons } from '@aussieljk/forkbook/manager-api';

addons.setConfig({
  sidebar: {
    showRoots: true,
    collapsedRoots: ['other'],
    showIcons: false,
    expandAll: true,
    flat: false,
  },
});
```

| Option | Default | What it does |
|---|---|---|
| `showRoots` | `true` | Shows the top-level groups as headings. |
| `collapsedRoots` | `[]` | The ids of the top-level groups that start closed. |
| `showIcons` | `false` | Shows a grey type icon (group, component, docs, story) before each item. |
| `expandAll` | `true` | Opens every group and component when Forkbook starts. Set `false` to open only the top-level groups. |
| `flat` | `false` | Removes all folders. The sidebar shows each item at the top level. |

## One leaf for a story

When the name of a story is the same as its title, the sidebar shows one item (a leaf) for the story. It does not show a component with one story in it. This is also true when autodocs is on. [A story for each page](/docs/get-started/frameworks/nextjs-pages) uses this rule.

The sidebar uses neutral greys for hover and for the selected item.
