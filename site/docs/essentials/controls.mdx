# Controls

The Controls panel shows the args of a story. Change an arg and the story changes.

Forkbook makes the controls from your TypeScript types. To change a control, use [argTypes](/docs/api/arg-types#control).

## Annotation

```tsx
const meta = {
  component: Button,
  argTypes: {
    variant: { control: 'radio', options: ['primary', 'secondary'] },
    size: { control: { type: 'range', min: 8, max: 48, step: 2 } },
  },
} satisfies Meta<typeof Button>;
```

## Custom control type matchers

Forkbook can choose a control from the name of an arg. Set `controls.matchers` in `.forkbook/preview.ts`:

```ts
parameters: {
  controls: {
    matchers: { color: /(background|color)$/i, date: /Date$/i },
  },
}
```

## Fully custom args

An arg does not have to be a prop. Add it in `argTypes` and use it in `render`:

```tsx
export const Many: Story = {
  argTypes: { count: { control: { type: 'number', min: 1, max: 10 } } },
  args: { count: 3 },
  render: ({ count, ...args }) => (
    <>{Array.from({ length: count }, (_, i) => <Button key={i} {...args} />)}</>
  ),
};
```

## Parameters

| Parameter | What it does |
| --- | --- |
| `controls.expanded` | Shows the description and the default value. |
| `controls.include`, `controls.exclude` | Which args to show. Names or a regular expression. |
| `controls.sort` | `none`, `alpha` or `requiredFirst`. |
| `controls.presetColors` | Colours for all colour controls. |
| `controls.disableSaveFromUI` | Hides the button that saves args to the story file. |
| `controls.disable` | Set to `true` to remove the panel for a story. |

## Disable

Set `features: { controls: false }` in `.forkbook/main.ts`, or `parameters: { controls: { disable: true } }` for one story.

## On React Native

The on-device Controls panel is `@aussieljk/forkbook/addon-ondevice-controls`. It uses the SwiftUI slider and date picker of Expo UI.
